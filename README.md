# PrintBot — بوت تيليجرام للطباعة المباشرة (ويندوز)

تطبيق شخصي بواجهة عربية (RTL) يستقبل ملفات PDF/PNG/JPG على تيليجرام، يطبعها مباشرة على طابعتك (USB أو شبكة) دون فتح أي نافذة — مع تثبيت بنقرة واحدة، دعم عدة مستخدمين، ودليل استخدام مدمج.

الإصدار الحالي: **1.1.0**

## المزايا

- **تثبيت بنقرة واحدة** عبر مُثبّت (Inno Setup) إلى `%LOCALAPPDATA%\Programs\PrintBot` دون صلاحيات إدارية.
- **أيقونة نظام (Tray)** تبقى في الخلفية؛ البوت يعمل تلقائياً عند التشغيل.
- **معالج إعداد أول** يكتشف توكن البوت و Chat ID تلقائياً (مع إمكانية الإدخال اليدوي).
- **عدة مستخدمين مصرح لهم**: قائمة Chat IDs تُدار من الإعدادات، مع موافقة تلقائية على أي مستخدم جديد.
- **إدارة الطابعات** من نافذة رسومية: اكتشاف تلقائي + إضافة يدوية + صفحة اختبار.
- **تحسين وضوح الصور** اختياري من داخل محادثة البوت (تحسين أو الاحتفاظ بالأصل).
- **أمر `/status`** للتحقق من أن البوت يعمل وجاهز + رسالة جاهزية تُرسل عند التشغيل.
- **كشف التعارض (HTTP 409)** عند تشغيل نفس التوكن على جهازين وعرضه بوضوح.
- **سجل طباعة** داخل التطبيق مع حفظ في `%APPDATA%\PrintBot\logs`.
- **دليل استخدام** و**شاشة حول/التحديثات** مدمجان في التطبيق.

## التثبيت (للمستخدم النهائي)

### الطريقة الأولى: المُثبّت (موصى بها)

1. حمّل `PrintBotSetup-1.1.0.exe` (أو ابْنِه كما في قسم "البناء" أدناه).
2. شغّل المُثبّت واتبع الخطوات — يُثبَّت إلى `%LOCALAPPDATA%\Programs\PrintBot` بدون صلاحيات إدارية.
3. بعد التثبيت يبدأ التطبيق تلقائياً ويظهر في **أيقونات النظام** (بجانب الساعة، قد يكون تحت سهم `^`).
4. سيظهر **معالج الإعداد الأول**:
   - أنشئ بوتاً من `@BotFather` في تيليجرام وانسخ التوكن والصقه.
   - أرسل `/start` لبوتك من تيليجرام، ثم اضغط **"تفويض هذا الحساب"** (أو أدخل Chat ID يدوياً).
5. من قائمة **"الطابعات"** أضف طابعاتك (اختر من القائمة أو أدخل الاسم يدوياً) واضغط **"صفحة اختبار"** للتأكد، ثم **"تعيين كافتراضي"**.
6. أرسل ملف PDF أو صورة لبوتك من تيليجرام واختر الطباعة السريعة أو المخصصة.

> ملاحظة: عند التشغيل الأول إذا ظهرت رسالة "يعمل بالفعل"، فهذا يعني أن التطبيق يعمل في الخلفية — افتحه من أيقونة النظام.

### الطريقة الثانية: التشغيل من المصدر (للمطوّر)

المتطلبات: Python 3.12 (و `pip`).

```bash
# (اختياري) بيئة افتراضية معزولة
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# تثبيت المتطلبات
pip install -r requirements.txt

# التشغيل (الأخطاء تظهر في الطرفية)
python app/main.py
```

## أوامر البوت (من تيليجرام)

| الأمر | الوصف |
| --- | --- |
| `/start` | بدء الاستخدام |
| `/status` | التحقق من أن البوت يعمل وجاهز |
| `/whoami` | معرفة Chat ID الخاص بك |

- أرسل **ملف PDF** أو **صورة PNG/JPG** للطباعة.
- للصور: اختر **"تحسين الوضوح"** أو **"بدون تحسين"** ثم اختر الطباعة السريعة أو المخصصة.

## البناء (للمطوّر)

```bash
pip install -r requirements.txt pyinstaller
powershell -ExecutionPolicy Bypass -File build.ps1
```

- الناتج: مجلد `dist\PrintBot` (قابل للتوزيع مباشرة).
- المُثبّت `PrintBotSetup-1.1.0.exe` يُنشأ تلقائياً إذا كان [Inno Setup 6](https://jrsoftware.org/isinfo.php) مثبّتاً (اختياري).

## بنية المشروع

```
app/
  main.py          نقطة الدخول (RTL + منع النسخ المزدوج + تشغيل تلقائي)
  config.py        إعدادات %APPDATA%\PrintBot\config.json
  strings.py       نصوص الواجهة العربية (مركزية + الإصدار)
  printers.py      اكتشاف الطابعات (win32print)
  autostart.py     تسجيل التشغيل التلقائي (HKCU Run)
  bot_runner.py    بوت تيليجرام (خيط منفصل + معالجات الطباعة + /status)
  tray_app.py      واجهة Qt (أيقونة النظام + الإعدادات + الطابعات + المعالج + الدليل)
print_utils.py     الطباعة الصامتة عبر SumatraPDF + صفحة اختبار
image_enhance.py   تحسين وضوح الصور + تحويل صورة إلى PDF
SumatraPDF.exe     عارض PDF المحمول (GPLv3 — يُحزم مع التطبيق)
PrintBot.ico       أيقونة التطبيق
build.ps1          سكربت البناء (PyInstaller + Inno Setup)
```

## ملاحظات

- **البيانات** تُحفظ في `%APPDATA%\PrintBot\` (الإعدادات، السجل، الملفات المؤقتة) وتُحفظ عند التحديث/إعادة التثبيت.
- **التوكن** يُحفظ نصاً عادياً في `config.json` على جهازك — لا تُشاركه ولا تُرفعه إلى المستودعات (يُستثنى عبر `.gitignore`).
- **SumatraPDF** مرخّص تحت GPLv3 ويُوزَّع كما هو مع إسناد في نافذة "حول التطبيق والتحديثات".
- الجهاز يجب أن يبقى يعمل (والأيقونة في الخلفية) لاستقبال الرسائل وطباعتها.
